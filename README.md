# MD5 Implementation

My personal implementation of the MD5 hashing algorithm in Python, built to understand how it works internally.

---

## How to Use

Calculate the MD5 hash of a string:

```bash
python Md5.py -s "Hello World!"
```

Calculate the MD5 hash of a file:

```bash
python Md5.py -f my_file.txt
```

Display available options:

```bash
python Md5.py --help
```
